# Smart Trading Telegram Bot

بوت Telegram للتحليل الفني والتنبيهات فقط، يعمل على Termux. لا ينفذ أوامر تداول ولا يتصل بوسيط للكتابة.

## الوظائف

- RSI وPrice Action Engulfing مع فلتر اتجاه اختياري.
- فلترة متعددة: Engulfing + RSI + اتجاه EMA20/EMA50 لتقليل الإشارات داخل النطاقات.
- درع DXY: يتطلب اتجاهًا مؤكدًا لمؤشر الدولار قبل تمرير إشارات الذهب/الفضة والأزواج المرتبطة بالدولار.
- فلتر أخبار عالي التأثير بنظام fail-closed؛ عند عدم توفر تقويم موثوق لا يرسل البوت إشارة.
- عند قرب خبر عالي التأثير، يعمل الوضع التكيفي بدل الحظر: يشترط Liquidity Sweep وBollinger overextension وRSI divergence واتجاه EMA قبل قبول الإشارة.
- يضيف أوامر `/analytics` و`/report` لتلخيص حالة المحرك والإشارات المقيمة.
- رموز MT5 قياسية صريحة مثل EURUSD وUSDCAD وUSDJPY وXAUUSD وBTCUSD؛ لا يتم توليد رموز معكوسة تلقائيًا.
- مخاطرة نموذجية 1% وحجم وحدات/لوت نظري قابل للتهيئة؛ لا يرسل أمرًا.
- سجل SQLite للإشارات، نتائجها اللاحقة، وتقرير أداء تراكمي.
- تعلم ذاتي محافظ: يتابع الإشارات المفتوحة، يحسم نتيجة افتراضية عند -1R أو +1.5R، ويحدّث أوزان الفلاتر ضمن حدود ثابتة بعد عينة كافية. اعرضه عبر `/learning`.
- عند ظهور إشارة، يعرض البوت أزرار سكالبينج ومتوسط المدى وبعيد المدى؛ لا تظهر مستويات SL/TP إلا بعد اختيار النمط.
- يحسب كل نمط SL وTP1 وTP2 وTP3 من نطاق الشمعة واتجاه BUY/SELL بمضاعفات متدرجة.
- أزرار تحديث التحليل، تشغيل/إيقاف التنبيهات، تسجيل خطة حجز الأرباح، وتقييم الإشارة.
- رفض البيانات الفارغة أو القديمة، وتسجيل مصدر ووقت كل قراءة.
- مزود الأسعار الافتراضي هو Yahoo Finance ويعمل مباشرة على Termux دون جسر خارجي؛ يمكن إضافة جسر وسيط لاحقًا اختياريًا.
- تشغيل مستمر على Termux باستخدام tmux.
- مسح متوازٍ مضبوط عبر `MAX_CONCURRENT_FETCHES` لتقليل زمن فحص القائمة دون إرسال طلبات مفرطة إلى Yahoo.

## حدود مهمة

بيانات Yahoo Finance قد تكون متأخرة أو غير متاحة لبعض رموز الفوركس/المعادن، وقد تختلف عن سعر وسيط MT5 بسبب السبريد ومصدر التسعير والشموع. التوازي يقلل زمن المسح لكنه لا يجعل مزود Yahoo بثًا دون تأخير أو يضمن فحصًا في أقل من ثانية. لذلك لا يمكن ضمان تطابق 100% أو دقة تنفيذية أو ربحية دون تغذية MT5 مباشرة واختبارات تاريخية وبيانات مواصفات العقد لكل رمز. البوت يذكر ذلك في الرسائل ولا يحولها إلى أسعار تنفيذية.

## التشغيل السريع على Termux

```bash
pkg update && pkg install python tmux git -y
bash install_termux.sh
cp .env.example .env
nano .env
bash run_tmux.sh
```

ضع `TELEGRAM_BOT_TOKEN` في `.env` فقط، ولا ترفع الملف إلى GitHub. راجع السجل عبر `tmux attach -t smart-trading-bot`.

عند استخدام فلتر الأخبار الإجباري، أنشئ `data/news_events.json` من قالب `data/news_events.example.json` أو اضبط `NEWS_EVENTS_URL` على مصدر HTTPS موثوق يعيد قائمة `events` بالحقول `time` و`impact` و`currencies` و`title`. لا تستخدم بيانات قديمة؛ عند غياب المصدر سيحجب البوت الإشارة بدلاً من التخمين. قيمة `DXY_SYMBOL` الافتراضية هي `DX-Y.NYB` عبر Yahoo Finance.

في وضع Yahoo تُستخدم خرائط مرجعية مثل `EURUSD=X` و`GC=F` للذهب و`SI=F` للفضة و`BTC-USD` للبيتكوين. هذه أسعار مرجعية عامة وقد تكون متأخرة أو تختلف عن وسيط MT5، لذلك لا يعرضها البوت كسعر تنفيذ أو كسعر مطابق للسيولة الخاصة بالوسيط.

### جسر الأسعار الحي للوسيط/MT5

على Termux لا توجد مكتبة MetaTrader5 الأصلية التي تتصل مباشرة ببرنامج MT5 على Windows. للحصول على أسعار الوسيط نفسه، شغّل جسرًا على جهاز أو خادم يمكنه الوصول إلى MT5، واضبط `BROKER_FEED_URL` و`BROKER_FEED_TOKEN` في `.env`. يجب أن يعيد الجسر JSON بالشكل التالي:

```json
{
  "symbol": "EURUSD",
  "source": "broker-name-live-feed",
  "bid": 1.08510,
  "ask": 1.08522,
  "candles": [
    {"time": "2026-11-03T20:45:00Z", "open": 1.0849, "high": 1.0853, "low": 1.0847, "close": 1.0851}
  ]
}
```

يجب أن تكون الشموع وBid/Ask من نفس مزود السيولة وبنفس المنطقة الزمنية والفاصل. يستخدم البوت Ask للشراء وBid للبيع عند توفرهما، ويرفض الرمز إذا كان المصدر غير متاح أو البيانات قديمة. لا تفعّل `ALLOW_PUBLIC_FALLBACK` للإنتاج؛ Yahoo لا يضمن تطابق وسيط MT5.

## أوامر Telegram

`/start`، `/setbalance 1000`، `/scan`، `/watchlist`، `/analytics`، `/report`، `/learning`، `/performance`، `/pause`، `/resume`، `/help`.

التعلم هنا تقييم افتراضي لحركة السعر من مصدر Yahoo، وليس نتيجة تنفيذ أو صفقة حقيقية. لا يغيّر الأوزان قبل 20 عينة افتراضية افتراضيًا، ويضع حدًا أدنى وأقصى لكل وزن لتقليل الانحراف والإفراط في التخصيص.
