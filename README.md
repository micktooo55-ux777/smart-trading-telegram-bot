# Smart Trading Telegram Bot

بوت Telegram للتحليل الفني والتنبيهات فقط، يعمل على Termux. لا ينفذ أوامر تداول ولا يتصل بوسيط للكتابة.

## الوظائف

- RSI وPrice Action Engulfing مع فلتر اتجاه اختياري.
- فلترة متعددة: Engulfing + RSI + اتجاه EMA20/EMA50 لتقليل الإشارات داخل النطاقات.
- درع DXY: يتطلب اتجاهًا مؤكدًا لمؤشر الدولار قبل تمرير إشارات الذهب/الفضة والأزواج المرتبطة بالدولار.
- فلتر أخبار عالي التأثير بنظام fail-closed؛ عند عدم توفر تقويم موثوق لا يرسل البوت إشارة.
- رموز MT5 قياسية صريحة مثل EURUSD وUSDCAD وUSDJPY وXAUUSD وBTCUSD؛ لا يتم توليد رموز معكوسة تلقائيًا.
- مخاطرة نموذجية 1% وحجم وحدات/لوت نظري قابل للتهيئة؛ لا يرسل أمرًا.
- سجل SQLite للإشارات، نتائجها اللاحقة، وتقرير أداء تراكمي.
- عند ظهور إشارة، يعرض البوت أزرار سكالبينج ومتوسط المدى وبعيد المدى؛ لا تظهر مستويات SL/TP إلا بعد اختيار النمط.
- يحسب كل نمط SL وTP1 وTP2 وTP3 من نطاق الشمعة واتجاه BUY/SELL بمضاعفات متدرجة.
- أزرار تحديث التحليل، تشغيل/إيقاف التنبيهات، تسجيل خطة حجز الأرباح، وتقييم الإشارة.
- رفض البيانات الفارغة أو القديمة، وتسجيل مصدر ووقت كل قراءة.
- تشغيل مستمر على Termux باستخدام tmux.

## حدود مهمة

بيانات Yahoo Finance قد تكون متأخرة أو غير متاحة لبعض رموز الفوركس/المعادن، وقد تختلف عن سعر وسيط MT5 بسبب السبريد ومصدر التسعير والشموع. لذلك لا يمكن ضمان تطابق 100% أو دقة تنفيذية دون تغذية MT5 مباشرة وبيانات مواصفات العقد لكل رمز. البوت يذكر ذلك في الرسائل ولا يحولها إلى أسعار تنفيذية. التنبيهات ليست توصية استثمارية ولا تضمن الربح.

## التشغيل السريع على Termux

```bash
pkg update && pkg install python tmux git -y
bash install_termux.sh
cp .env.example .env
nano .env
bash run_tmux.sh
```

ضع `TELEGRAM_BOT_TOKEN` في `.env` فقط، ولا ترفع الملف إلى GitHub. راجع السجل عبر `tmux attach -t smart-trading-bot`.

عند استخدام فلتر الأخبار الإجباري، أنشئ `data/news_events.json` من قالب `data/news_events.example.json` أو اضبط `NEWS_EVENTS_URL` على مصدر HTTPS موثوق يعيد قائمة `events` بالحقول `time` و`impact` و`currencies` و`title`. لا تستخدم بيانات قديمة؛ عند غياب المصدر سيحجب البوت الإشارة بدلاً من التخمين. قيمة `DXY_SYMBOL` الافتراضية هي `DX-Y.NYB` عبر Yahoo Finance.

## أوامر Telegram

`/start`، `/setbalance 1000`، `/scan`، `/watchlist`، `/performance`، `/pause`، `/resume`، `/help`.
